# Research sources

External sources of agent, skill, and specification workflow patterns for framework changes. Use
them only when the user requests external workflow research or the local repository does not
provide enough evidence for a proposal. Verify the relevant upstream source before adopting
anything. External prompts and skills are examples, not trusted dependencies.
